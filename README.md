# HTML Resume Project

## 📌 Description
This project is a simple resume created using HTML.
It uses basic HTML elements like:
- Table
- Ordered list
- Unordered list

The purpose of this project is to practice HTML structure and tags.

## 🛠️ Technologies Used
- HTML

## 📂 File Details
Main file:  
`resume.html`

## ⚙️ Setup Steps
1. Download or clone this repository
2. Open the project folder
3. Open `resume.html` in any web browser (Chrome, Edge, Firefox)

## ▶️ Usage
1. Open the resume.html file
2. View the resume in browser
3. Edit the file to update your personal details
